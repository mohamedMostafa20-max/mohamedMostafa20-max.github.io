Tapered column — finite-element mesh convergence

To reproduce a case in SAP2000: model the column as one frame member (non-prismatic section for tapered), add rotational springs k at both ends using the values printed in the worked solution, restrain the base laterally (and the top too for a braced frame), apply a 1 kN axial load and run a Buckling load case. The first buckling factor is Pcr in kN.

Prismatic columns: K from the exact alignment-chart equations (AISC Commentary C-A-7-1 / C-A-7-2, same charts used by ECP), solved numerically. Tapered columns: elastic finite-element buckling (60 elements) with joint springs k = 6EIc/(LcG) for sway or 2EIc/(LcG) for braced frames, which reproduces the chart equations exactly for prismatic members; K is referred to the smaller end. Beam far-end factors m follow AISC Commentary Appendix 7.
