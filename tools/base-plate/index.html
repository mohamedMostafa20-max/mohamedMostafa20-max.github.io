Benchmark check of the calculation engine▾

Each time the application opens it re-runs a benchmark example (the original hand-checked reference calculation, Rev. 3) and compares every key result with its reference value. The application solves the neutral axis and the pedestal strain compatibility exactly, where the reference interpolates on a grid, so tiny differences (well below 0.1 %) are expected. Rows marked “ref.” were changed on purpose to follow ECP 205 Table 2.7.

Method: ECP 205 (ASD / LRFD) for the base plate, prying, weld, anchor bolt and washer plate; ACI 318-19 Chapter 17 (SI, f′c = 0.8 fcu, cracked concrete; ASD allowable = φNn/1.5) for concrete anchorage; ECP 203 for the pedestal section. Column Base Designer v1.0.
